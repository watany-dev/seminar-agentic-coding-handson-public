# セミナー申込受付

セミナーの申込とキャンセルを受け付ける小さなWebアプリです。ハンズオンの教材として使います。

## 動かす

```sh
npm ci        # 依存関係のインストール（Codespacesでは起動時に実行済み）
npm run dev   # http://localhost:3000 で起動
```

Codespacesでは、起動するとポート3000の画面がプレビューで開きます。データはメモリ上にあります。ソースを変更するとサーバーが自動で再起動し、初期状態に戻ります。

| 目的 | コマンド |

| テスト | `npm test`（1回実行して終了） |

## 仕様

### 申込

- 名前とメールアドレスが必要です。メールアドレスは形式を確認します。
- 申込締切の時刻までは受け付けます。締切を過ぎたら受け付けません。
- 申込数が定員に達したら受け付けません。残席は「定員 − 申込数」で、0より小さくなりません。
- 同じセミナーに同じメールアドレスでは申し込めません（大文字小文字は区別しません）。

### キャンセル

- 開催日時の7日前までは、受講料から手数料500円を引いて返金します。
- それを過ぎたら返金しません。

## 構成

| 場所 | 内容 |
| --- | --- |
| `src/rules.ts` | 申込・返金のルール |
| `src/store.ts` | メモリ上のデータと初期データ |
| `src/app.ts` | HTTPの入口（`/api` 以下がJSON API、それ以外は画面） |
| `src/server.ts` | 起動スクリプト |
| `public/` | 画面（HTML・CSS・JavaScript） |
| `test/` | テスト |
